Add a phone

Scan from your phone

Open Developer options → Wireless debugging → Pair device with QR code.

Use Android 11 or newer on the same Wi-Fi network. Scan from Wireless debugging, not the normal camera app.

Preparing QR code…

Open Wireless debugging → Pair device with pairing code on your phone.

Enter the address shown on your device. You can also paste a complete IP:port.

Already paired, but not connected?

Use the connection port on the main Wireless debugging screen. It is different from the pairing port and can change when wireless debugging restarts.

Connect with a data cable

  1. Enable Developer options → USB debugging on the phone.
  2. Plug the phone into this computer with a USB data cable.
  3. Unlock the phone and accept Allow USB debugging.

It will appear in Devices automatically. If it shows “unauthorized”, approve the prompt on the phone. On Linux, a “no permissions” message usually needs your distribution’s Android USB rules.
